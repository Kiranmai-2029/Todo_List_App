📝 To-Do List App

A simple and interactive To-Do List application that helps users organize their daily tasks, manage priorities, and track completed activities.

🚀 Features
➕ Add new tasks
✏️ Edit existing tasks
🗑️ Delete tasks
✅ Mark tasks as completed
📋 View all tasks
🎨 Simple and user-friendly interface
📱 Responsive design

🛠️ Technologies Used
HTML5
CSS3
JavaScript

📂 Project Structure
text
todo-list/
│
├── index.html

⚙️ Installation and Setup
Clone this repository:
bash
git clone <your-repository-url>

Open the project folder.
Open index.html in your web browser.

💻 How to Use
Enter your task in the input field.
Click the Add button.
View your tasks in the task list.
Mark tasks as completed when finished.
Edit or delete tasks whenever needed.

🎯 Project Objective

The main objective of this project is to improve productivity and task management by providing a simple digital platform to organize daily activities.
